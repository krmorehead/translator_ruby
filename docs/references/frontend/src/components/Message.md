# frontend/src/components/Message.jsx

## Summary
- Individual chat bubble component.
- Styles differ for user vs assistant messages.

## Key Behaviors
- Receives `source` and `message`; chooses alignment and label based on `source`.
- Displays message text with proper styling classes.

## Props
- `source` (string), `message` (string).

## Related
- Used by `ChatLog.jsx`.
