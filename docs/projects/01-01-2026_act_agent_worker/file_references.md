# File References: Sisyphus Agent Worker

## Overview

This project creates **SisyphusWorker** - an autonomous execution agent that executes structured plans generated by the PlanAgentWorker. Named after the Greek hero condemned to push a boulder uphill eternally, Sisyphus processes plans step-by-step with visual diffs, Git checkpoints, real-time progress streaming, and intelligent error recovery. Inspired by Cline's "Act Mode" but adapted to our OOP architecture and autonomous execution model.

## Prompt Architecture Clarity

All 7 prompts work together in this order:

```
User provides ExecutionPlan
         ↓
[SisyphusSystemPrompt] ← Always included in every LLM call
         ↓
For each step:
         ↓
[ContextAssemblyPrompt] → Gather needed context
         ↓
[StepPlanningPrompt] → Plan tool calls
         ↓
[ToolValidationPrompt] → Validate each tool call
         ↓
[StepExecutionPrompt] → Execute with full context
         ↓
[StepEvaluationPrompt] → Check completion
         ↓
If failed → [ErrorRecoveryPrompt] → Retry or continue
         ↓
Next step or milestone complete
```

This architecture ensures:
- Clear separation of concerns
- Better testability
- Easier debugging
- Comprehensive validation
- Intelligent error recovery
